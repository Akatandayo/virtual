# 承太郎ボット（統合版マインクラフト用）

AI（Claude）が空条承太郎としてサーバーに参加し、自分で考えて動くプレイヤーです。
チャットで会話し、ついて来て、敵と戦い、スタンドアドオンのスタープラチナ（3部）を使います。

- 承太郎の口調で会話する（人格は `brain/persona.md` で調整できる）
- 誰にも頼まれていないときも、自分で考えて動く
- スタープラチナを出す・しまう、ラッシュ、スターフィンガー、吸い込み、時止め
- 移動、追従、戦闘、採掘、ブロック設置、簡易クラフト、食事、アイテムの受け渡し
- モブに殴られたら、指示を待たずに反撃する

## 仕組み

| 部分 | 場所 | 役割 |
|---|---|---|
| 体 | `behavior_pack/` | サーバー内で動くスクリプト。模擬プレイヤーを出現させ、行動を実行し、状況を頭脳へ送る |
| 見た目 | `resource_pack/` | 承太郎のスキンを表示する |
| 頭脳 | `brain/` | サーバーと同じPCで動かすプログラム。状況を Claude に渡して次の行動を決めさせる |

## 必要なもの

- Windows のPCと、公式の統合版サーバー（Bedrock Dedicated Server）。動作確認したのは 1.26.63.1
- [Node.js](https://nodejs.org/)（バージョン 20.12 以上）
- Claude の APIキー（[platform.claude.com](https://platform.claude.com/) で発行。使った分だけ課金される）
- スタンドアドオンの `.mcaddon` ファイル。作者が再配布を禁止しているので、このリポジトリには入っていない

## セットアップ

1. 統合版サーバーを一度起動してワールドを作り、`stop` で止める。
2. このフォルダ（`jotaro-bot`）をPCに置く。
3. コマンドプロンプトで、サーバーのフォルダとアドオンのファイルを指定してインストールする。

   ```bat
   install.bat "C:\bedrock-server" "C:\Downloads\jojo_stand_disc.mcaddon"
   ```

   アドオンをすでにサーバーへ入れてある場合は、2つ目の指定を省く。

4. サーバーの `server.properties` を開き、`texturepack-required=true` にする（承太郎の見た目を全員に表示するため）。
5. `start-brain.bat` をダブルクリックする。初回はメモ帳が開くので、`ANTHROPIC_API_KEY=` の後ろにAPIキーを書いて保存し、閉じる。
6. 統合版サーバーを起動して、マインクラフトから参加する。数秒後に承太郎が隣に現れる。

サーバーを更新したりワールドを作り直したりしたときは、手順3をやり直す。

## 遊び方

普通にチャットで話しかける。「ついて来い」「あのゾンビを倒してくれ」「スタープラチナを見せて」「木を集めてくれ」など。

困ったとき用のチャットコマンド:

| コマンド | 動作 |
|---|---|
| `!jotaro here` | 自分の場所に承太郎を呼び寄せる（はまって動けないときに） |
| `!jotaro stop` | いましている行動をやめさせる |
| `!jotaro remove` | 退出させる |
| `!jotaro spawn` | もう一度出現させる |

サーバーのコンソールからは `scriptevent jobot:spawn`、`scriptevent jobot:remove`、`scriptevent jobot:chat こんにちは` が使える。

人間のプレイヤーが全員抜けると、承太郎も退出する（位置と持ち物は保存される）。

## 設定

- `brain/.env` — APIキー、使うモデル、考える深さ、自分から動く間隔、呼び出し回数の上限
- `brain/persona.md` — 人格と話し方
- `behavior_pack/scripts/config.js` — プレイヤー名、自動反撃、スタンドを持たせるか、など（変更したら手順3をやり直す）
- `brain/memory.json` — 承太郎が覚えたメモと現在の目標（自動で作られる。消すと忘れる）

### 料金について

考えるたびにAPIの料金がかかる。実測はしていないが、標準設定（Opus 5.5、60秒ごとに自発行動）で遊ぶと1時間あたり数ドルになる見込み。
抑えたいときは `brain/.env` で次のように変える。

- `MODEL=claude-haiku-5-5` にする（料金は数十分の一。判断は粗くなる）
- `IDLE_SECONDS` を大きくする（自分から動く頻度が下がる）
- `MAX_CALLS_PER_HOUR` を小さくする（上限に達するとその時間は考えなくなる）

頭脳プログラムの画面に、累計のトークン数が表示される。

## 確認できていること・いないこと

統合版サーバー 1.26.63.1 に実際のスタンドアドオンを入れて、次の動作を確認した。

- 出現、チャット、移動、戦闘、自動反撃、採掘、設置、クラフト、食事、死亡からの復活
- ディスクでスタンドを出す、しまう、ラッシュで敵を倒す、時止め
- 退出と再参加で位置と持ち物が戻る
- サーバーのチート設定がオフでも動く

次の3点は、こちらの環境では確認できていない。

- **承太郎スキンの表示**。表示はゲーム画面側の処理なので未確認。スティーブのままだった場合は連絡してほしい
- **本物の Claude との会話**。APIキーが無いため、決め打ちの応答を返す代役で通しテストをした
- **Windows での実行**。テストは Linux 版サーバーで行った

## 制限

- かまど、チェスト、エンチャント、取引などの画面操作はできない。クラフトは基本的な道具・防具・設備だけ
- 頭の装備枠は、スキン表示用の帽子で埋まっている
- 判断には数秒かかる。とっさの戦闘は自動反撃と `fight` の自動操作で補っている
- スタンドの技は範囲内の味方にも当たる。承太郎には仲間のそばで使わないよう指示してあるが、絶対ではない
- 模擬プレイヤーと外部通信はベータAPIなので、マインクラフトの更新で動かなくなることがある
- スタンドアドオンは 1.21.92 向けに作られていて、現行バージョンではタスクAct4のアイテムが読み込みエラーになる。スタープラチナには影響しない

## うまくいかないとき

- **承太郎が現れない** — サーバーの画面に `[jobot] 準備完了` と出ているか確認する。出ていなければ手順3をやり直す。
- **現れるが何もしない** — サーバーの画面に「頭脳プログラムに接続できません」と出ていたら、`start-brain.bat` を起動する。
- **頭脳の画面に「APIキーが正しくありません」** — `brain/.env` のキーを確認する。
- **同じPCのマインクラフトからサーバーに入れない** — Windows のループバック制限が原因のことがある。管理者のコマンドプロンプトで次を実行する。

  ```bat
  CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"
  ```
