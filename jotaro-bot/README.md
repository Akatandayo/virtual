# 承太郎ボット（統合版マインクラフト用）

AI（Claude）が空条承太郎としてサーバーに参加し、自分で考えて動くプレイヤーです。
チャットで会話し、ついて来て、敵と戦い、スタンドアドオンのスタープラチナ（3部）を使います。

- 承太郎の口調で会話する（人格は `brain/persona.md` で調整できる）
- 誰にも頼まれていないときも、自分で考えて動く
- スタープラチナを出す・しまう、ラッシュ、スターフィンガー、吸い込み、時止め
- 移動、追従、戦闘、採掘、ブロック設置、簡易クラフト、食事、アイテムの受け渡し
- モブに殴られたら、指示を待たずに反撃する

## 仕組み

| 部分 | 場所 | 役割 |
|---|---|---|
| 体 | `behavior_pack/` | サーバー内で動くスクリプト。模擬プレイヤーを出現させ、行動を実行し、状況を頭脳へ送る |
| 見た目 | `resource_pack/` | 承太郎のスキンを表示する |
| 頭脳 | `brain/` | サーバーと同じPCで動かすプログラム。状況を Claude に渡して次の行動を決めさせる |

## 必要なもの

- Windows 10 / 11 のPC（サーバーと頭脳を動かす）
- Claude の **Pro / Max プラン**（APIキーで動かすこともできる。後述）
- マインクラフト統合版（Windows版、スマホ版、Switch版など）
- スタンドアドオンの `.mcaddon` ファイル（作者が再配布を禁止しているので、この中には入っていない）

承太郎のスキンは同梱済み。

## セットアップ（初回のみ）

### 1. Node.js を入れる

1. [nodejs.org](https://nodejs.org/) を開き、「LTS」と書かれたほうの Windows 用インストーラーをダウンロードする。
2. ダウンロードしたファイルを開き、すべて既定のまま「Next」で進めてインストールする。
3. 確認する。スタートメニューで「cmd」と検索して「コマンドプロンプト」を開き、次を入力して Enter を押す。`v22.` のような番号が出ればよい。

   ```bat
   node -v
   ```

### 2. Claude Code を入れてログインする

1. スタートメニューで「PowerShell」と検索して開き、次を貼り付けて Enter を押す。しばらく何も表示されないが、終わるまで待つ。

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

2. PowerShell を一度閉じて開き直し、次を入力する。`2.1.` のような番号が出ればよい。

   ```powershell
   claude --version
   ```

3. 続けて `claude` と入力して Enter を押す。ブラウザが開くので、Pro プランのアカウントでログインする。
4. ログインが終わって入力欄が出たら、`/exit` と入力して閉じる。これ以降、承太郎はこのログインを使って考える。

### 3. 統合版サーバーを用意する

1. [minecraft.net のサーバーダウンロードページ](https://www.minecraft.net/download/server/bedrock)を開き、利用規約に同意して **Windows 用** をダウンロードする。
2. zip ファイルを右クリック →「すべて展開」で、たとえば `C:\bedrock-server` に展開する。
3. フォルダ内の `bedrock_server.exe` をダブルクリックする。ファイアウォールの確認が出たら「許可」する。
4. 黒い画面に `Server started.` と出たら、その画面に `stop` と入力して Enter を押し、止める（ワールドが作られる）。

サーバーとマインクラフトのバージョンは同じでないと参加できない。どちらかが古い場合は更新する。

### 4. 承太郎ボットを置く

1. このフォルダ（`jotaro-bot`）を、たとえば `C:\jotaro-bot` に置く。
2. `C:\bedrock-server\server.properties` をメモ帳で開き、`texturepack-required=false` を `texturepack-required=true` に書き換えて保存する（承太郎の見た目を全員に表示するため）。

### 5. インストールする

コマンドプロンプトを開き、次を1行ずつ入力する。2行目の2つの場所は、自分の環境に合わせて書き換える。

```bat
cd /d C:\jotaro-bot
```

```bat
install.bat "C:\bedrock-server" "C:\Users\あなたの名前\Downloads\jojo_stand_disc_1.mcaddon"
```

ファイルの場所は、エクスプローラーからファイルをコマンドプロンプトの画面へドラッグすると貼り付けられる。
`完了しました` と出れば成功。アドオンをすでにサーバーへ入れてある場合は、2つ目の指定を省く。

### 6. 頭脳を起動する

`C:\jotaro-bot\start-brain.bat` をダブルクリックする。

- 初回は部品のダウンロードが走り、そのあと設定ファイル（`.env`）がメモ帳で開く。Pro プランで動かすなら何も変えずに閉じる。
- `頭脳を起動しました` と出たら準備完了。この画面は遊んでいる間、開いたままにしておく。

### 7. サーバーを起動して参加する

1. `C:\bedrock-server\bedrock_server.exe` をダブルクリックする。画面に `[jobot] 準備完了` と出ていることを確認する。
2. マインクラフトを起動し、「遊ぶ」→「サーバー」→「サーバーを追加」を選ぶ。
   - 同じPCから入る場合: アドレス `127.0.0.1`、ポート `19132`
   - 同じ家の別の端末から入る場合: アドレスにサーバーPCのIPアドレス（コマンドプロンプトで `ipconfig` を実行し、「IPv4 アドレス」に出る番号）、ポート `19132`
3. 参加するとリソースパックのダウンロードを聞かれるので、許可する。
4. 数秒後、隣に承太郎が現れる。頭脳の画面に `体と接続しました` と出る。

## 2回目以降の起動

1. `start-brain.bat` をダブルクリックする。
2. `bedrock_server.exe` をダブルクリックする。
3. マインクラフトから参加する。

終わるときは、サーバーの画面で `stop` と入力し、頭脳の画面を閉じる。
サーバーを更新したり、新しいワールドに変えたりしたときは、手順5をやり直す。

## 遊び方

普通にチャットで話しかける。「ついて来い」「あのゾンビを倒してくれ」「スタープラチナを見せて」「木を集めてくれ」など。

困ったとき用のチャットコマンド:

| コマンド | 動作 |
|---|---|
| `!jotaro here` | 自分の場所に承太郎を呼び寄せる（はまって動けないときに） |
| `!jotaro stop` | いましている行動をやめさせる |
| `!jotaro remove` | 退出させる |
| `!jotaro spawn` | もう一度出現させる |

サーバーのコンソールからは `scriptevent jobot:spawn`、`scriptevent jobot:remove`、`scriptevent jobot:chat こんにちは` が使える。

人間のプレイヤーが全員抜けると、承太郎も退出する（位置と持ち物は保存される）。

## 設定

- `brain/.env` — 考える方式（Proプランか APIキーか）、使うモデル、考える深さ、自分から動く間隔、呼び出し回数の上限
- `brain/persona.md` — 人格と話し方
- `behavior_pack/scripts/config.js` — プレイヤー名、自動反撃、スタンドを持たせるか、など（変更したら手順3をやり直す）
- `brain/memory.json` — 承太郎が覚えたメモと現在の目標（自動で作られる。消すと忘れる）

### Pro プランで動かす場合（標準）

`BACKEND=claude-code` のとき、頭脳は Claude Code をあなたのログインで呼び出すので、APIの料金はかからない。代わりに次の点に注意する。

- プランの利用枠は、普段の Claude アプリや Claude Code と共通。承太郎が枠を使い切ると、枠が戻るまで承太郎は考えなくなり、あなた自身も Claude を使えなくなる
- 枠を長持ちさせるには `CLAUDE_CODE_MODEL=haiku`（標準）のままにして、`IDLE_SECONDS` を大きくする。話しかけたときと攻撃されたときだけ考える形に近づく
- `MAX_CALLS_PER_HOUR` で1時間あたりの呼び出し回数に上限をかけられる
- プログラムからの利用をプランの枠から切り離す変更が 2026年5月に発表され、6月に保留になったと報じられている。今後扱いが変わる可能性がある

### APIキーで動かす場合

`BACKEND=api` のとき、考えるたびにAPIの料金がかかる。実測はしていないが、Opus 5.5・60秒ごとの自発行動で遊ぶと1時間あたり数ドルになる見込み。
`MODEL=claude-haiku-5-5` にすると数十分の一になる。頭脳プログラムの画面に、累計のトークン数が表示される。

## 確認できていること・いないこと

統合版サーバー 1.26.63.1 に実際のスタンドアドオンを入れて、次の動作を確認した。

- 出現、チャット、移動、戦闘、自動反撃、採掘、設置、クラフト、食事、死亡からの復活
- ディスクでスタンドを出す、しまう、ラッシュで敵を倒す、時止め
- 退出と再参加で位置と持ち物が戻る
- サーバーのチート設定がオフでも動く

次の3点は、こちらの環境では確認できていない。

- **承太郎スキンの表示**。表示はゲーム画面側の処理なので未確認。スティーブのままだった場合は連絡してほしい
- **APIキー方式での実行**。APIキーが無いため、決め打ちの応答を返す代役でしか試していない。Claude Code 方式は本物の Claude（Haiku）で通しテストをし、会話、戦闘、頼まれての時止めが動くことを確認した
- **Windows での実行**。テストは Linux 版サーバーで行った。特に Claude Code の呼び出しは Windows で試せていない

## 制限

- かまど、チェスト、エンチャント、取引などの画面操作はできない。クラフトは基本的な道具・防具・設備だけ
- 頭の装備枠は、スキン表示用の帽子で埋まっている
- 判断には数秒かかる。とっさの戦闘は自動反撃と `fight` の自動操作で補っている
- スタンドの技は範囲内の味方にも当たる。承太郎には仲間のそばで使わないよう指示してあるが、絶対ではない
- 模擬プレイヤーと外部通信はベータAPIなので、マインクラフトの更新で動かなくなることがある
- スタンドアドオンは 1.21.92 向けに作られていて、現行バージョンではタスクAct4のアイテムが読み込みエラーになる。スタープラチナには影響しない

## うまくいかないとき

- **承太郎が現れない** — サーバーの画面に `[jobot] 準備完了` と出ているか確認する。出ていなければ手順3をやり直す。
- **現れるが何もしない** — サーバーの画面に「頭脳プログラムに接続できません」と出ていたら、`start-brain.bat` を起動する。
- **頭脳の画面に「claude コマンドが見つかりません」** — 手順2をやり直す。それでも出る場合は、`brain\.env` の `CLAUDE_PATH=` の後ろに `claude.exe` の場所を書く（PowerShell で `(Get-Command claude).Source` と入力すると場所が分かる）。
- **頭脳の画面に「プランの利用上限に達したようです」** — 枠が戻るまで待つ。頻繁に起きるなら `IDLE_SECONDS` を大きくする。
- **頭脳の画面に「APIキーが正しくありません」** — `brain/.env` のキーを確認する。
- **頭脳の画面に何も起きず、承太郎が黙っている** — 頭脳の画面に `体と接続しました` が出ているか確認する。出ていなければ、頭脳とサーバーを両方閉じて、頭脳→サーバーの順に起動し直す。
- **同じPCのマインクラフトからサーバーに入れない** — Windows のループバック制限が原因のことがある。管理者のコマンドプロンプトで次を実行する。

  ```bat
  CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"
  ```
