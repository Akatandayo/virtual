# ボスアドオン「東雲 永々（しののめ とあ）」（統合版） v1.8

宇宙から来た、年齢「んー分かんない、数億？」の女の子のボスです。**トリッキー型**で、分身・重力・ブラックホール・時間停止・ワープホール、そしてフランスパンで翻弄してきます。右手には黒胎刀（ネザライトの剣）、身長137cmなので少し小さめです。

## v1.8 の変更点
- **キャラの声を削除しました**（足音は残しています）。
- **同じ技を 2 回続けて使わなくなりました**（技の流れに変化が出ます）。
- **殴られたとき、ときどき間合いを取る**ようになりました（技を使っていないとき、約 2 割の確率で後ろへ跳んで遠距離で返す）。
- **その場で向きを変えるとき、足を踏み替える**ようになりました（滑るように回らない）。
- **瀕死（HP 15% 未満）では肩で息をする**ようになりました。

## v1.7 の変更点（ブラッシュアップ）
- **水の体が揺れる**：混沌の体（水）で近接攻撃を無効にした瞬間、ぷるんと揺れます。
- **足音**：歩く足音が鳴るようになりました。
- **瀕死の演出**：HP が 15% を切ると、足元から赤い火の粉が立ちのぼります。あと一息の合図です。

## v1.6 の変更点（間合いの判断）
- **近接の構え / 遠距離の構え**を、4 秒ごとに状況を見て選び直すようになりました（性格: 近接 60・遠距離 40、HP が 40% を切ると遠距離寄り）。
  - **近接の構え**: 相手に近づき、近距離の技と通常攻撃で戦います。
  - **遠距離の構え**: 近づかれたら離れ、13 マスくらいの距離を保ちながら、遠距離の技だけを使います。
- 新しいボス「月島 風花」とも敵対します（初めて出会ったときのひとこと付き）。

## v1.5 の変更点（近接攻撃のモーション・演出中のルール）
- **通常攻撃（近接）を 4 連コンボに作り直しました**：溜め → 踏み込みながら打つ → 振り抜き → 戻り、と全身を使うモーションです。振るたびに次の技へ切り替わります：叩き斬り → 前蹴り → 回転斬り → ジャンプ斬り
- **演出中は、ボス同士で手出しできなくなりました**：
  - どれかのボスの登場演出（ほかのカットシーンも）が始まると、近く（64 マス以内）のほかのボスはその場で一時停止し、演出が終わるまで攻撃しません。止まっている間は無敵です。
  - 演出中・一時停止中のボスは狙われず、技も当たりません。
  - 演出が終わると、自動で戦闘に戻ります。

## v1.4 の変更点（ボス同士の戦闘 AI を改良）
- **技の狙いが「一番近い敵」に**：プレイヤーだけでなく、ほかのボスにも技を向けて使うようになりました。ボス同士でも、瞬間移動・突進・飛び道具・範囲攻撃で戦います（プレイヤーとだけ戦うときの狙いは今までと同じ。クリエイティブのプレイヤーは狙いません）。
- **近距離技・遠距離技の選び方**も、プレイヤーではなく「一番近い敵」との距離で決めるようにしました。
- **立ち回りの技を追加**（プレイヤー相手にも使います）：
  - **ぴょーん**：後ろへぴょんと跳んで、星弾 3 発で返す
  - **くるっと回り込み（右・左）**：相手の横へ回り込みながら詰めて、横から攻撃する

## v1.3 の変更点
- **4体のボスが全員敵同士に**（白石白夜・電子 独・ソフィア・ハート・東雲 永々）：
  - ほかのボスのアドオンも入れていると、お互いを狙って戦い、**技も相手のボスに当たります**。
  - 初めて24マス以内で出会うと、ひとこと交わして「VS」が表示されます（白夜と独は、これまでどおり専用のカットシーン）。
  - 相手のアドオンが入っていなくても、エラーにはなりません。
- **アニメーションをさらになめらかに**：
  - モーションのキーを 1 秒あたり 20 → **50** に増やしました（ファイルは大きくなります）。
  - **技の出だしと終わりのつなぎ**を長めのクロスフェードに。技の最後のポーズから待機へ、ふわっと戻ります（回転技のあとも逆回転しません）。
  - **振り向き**：瞬間移動して振り向くときや、tick ごとに回る技も、なめらかな回転に見えるようにしました。
  - **走り出し・止まり際**：走りのモーションがゆっくり出入りします。待機中のしぐさも、走り出すとふわっと消えます。
  - **通常攻撃**：振り始めと振り終わりで腕の向きが飛ばないようにしました。
  - **のけぞり**：一瞬でのけぞって、なめらかに戻るようにしました（カクカクした段差をなくしました）。
  - 技の途中でポーズを止めているときも、わずかに呼吸して揺れるので、固まって見えません。

## v1.2 の変更点（アニメーション・演出のブラッシュアップ）

- **着弾の手応え**：大技が地面に当たると、破片が飛び散り、土煙の輪が広がります。

## 導入方法
1. `dist/ShinonomeToa_Boss.mcaddon` を開いて取り込みます。
2. ワールド設定で **東雲 永々 ボス BP / RP** の両方をオンにします（ほかのボスと同時に入れても大丈夫です）。
3. スポーンエッグを使うか、`/summon shinonome:toa` で呼び出します。

## 攻略の鍵
- **分身！！**：4体の分身を出して、入れ替わりながら紛れます。**本物は左目が金色に光っています**。
  - 分身を殴ると「ハズレ！」と言って爆風で吹き飛ばされます。
  - 本物を殴ると分身が全部消えて、東雲が2秒よろめきます。
- **混沌の体**：6秒間、水の体になります（体が青く揺れます）。**近接攻撃は効きません**が、**飛び道具は1.5倍**通ります。
- **狂化 → 気絶**（HP35%以下）：8秒間暴れ回ったあと、4秒間へたり込みます。気絶中はダメージが**1.5倍**通ります。
- **おやつタイム**：座ってハンバーガーを食べます（少し回復します）。3秒間動かないので攻めどきです。
- **オイルフランス → 炎**：オイルを浴びると「可燃」状態になり、しばらく炎のダメージ（火稲・炎龍）が**2倍**になります。炎耐性のポーションがあると安心です。

## 形態とカメラ演出
カットシーン中は、近くのプレイヤーはカメラを操作できず、移動もできません。そのかわりダメージを受けず、HUD も一時的に隠れます。東雲もその間はダメージを受けません。

| 場面 | 内容 |
|---|---|
| 登場 | 空にワープホールが開く → 見上げるカメラ → 落ちてきてくるっと着地 → 顔のアップで「ねえねえ、遊ぼ！」 |
| **シニスターの憑依**（HP65%） | 背中側からのカメラで、**クロノスピアの「窓」**が現れる → 正面 → 空撮。以降、黒いオーラをまとう |
| **全時間停止**（HP35%・必殺技） | 世界が灰色に止まる（霧と時計）→ 止まったプレイヤーの肩越しのショット → 周りにフランスパンが並ぶ → 時が動き出すと一斉に命中（16）。以降、狂化が解禁 |
| 撃破 | 座り込んでハンバーガーを食べ、「ばいばーい！」と手を振ってワープホールに消える → 「討伐成功」 |
| カットイン（v1.2） | マルチバースソードの前に空を見上げるカット、炎龍の前に顔のアップが一瞬入る |

## ほかのボスと一緒に
白石白夜・電子 独・ソフィア・ハートのアドオンも入れていると、**お互いを敵として攻撃し合います**。技も相手に当たります。初めて出会ったときは、ひとこと交わして「VS」が表示されます。

### おまけ：ソフィアと一緒に
ソフィア・ハートのアドオンも入れていて、東雲の近く（16マス以内）にソフィアがいると、東雲が一度だけ「おすわり！」と唱えます。**ソフィアは3秒間、土下座してしまいます**（キャラシのお札より）。

## 注意
- スコアボード `toa_players` を自動で作ります。
- 爆風はブロックを壊しませんが、近くの額縁や絵画は壊れることがあります。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。霧が残ったら `/fog @s remove toa_timestop` で消せます。
- キャラシの技のうち、他作品の固有技（黒閃・十種影法術・無限の剣製など）は、その作品の再現になってしまうため入れていません。

## 作り直し方（開発者向け）
スキンを差し替えるときは、スキン画像を指定して実行します（腕の太さは自動で判定します。Pillow が必要です）。

```bash
python3 tools/generate.py 東雲のスキン.png
```

2回目以降はスキンを省略すると、前回のスキンを使います。
