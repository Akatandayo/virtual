# ボスアドオン「電子 独」― 不具合・Glitch（自我の使者）（統合版） v1.2.1

ゲームのバグを具現化したようなノイズ能力「不具合・Glitch」を使うボスです。
**攻撃力は白石白夜より上、体力は700**。そのかわり、Glitch を壊さないとダメージが通りません。
HPが半分になると、「落下」の概念を操る **↓FREEDOM DiVE↓** の能力を解放し、BGMも切り替わります。

## v1.2.1 の変更点
- **モーションが動かなくなる不具合を修正**：v1.2 で追加した撃破演出のポーズの書き方が原因で、モーションのファイルごと読み込まれない可能性があったので直しました。
- データ弾・フォークボム・重力キューブ（欠損テクスチャのキューブ）が暗い所でも光るようにしました。
- 被弾時ののけぞりと、技を使いながら移動するときの足の動きを追加しました。

## 導入方法
1. `dist/DenshiHitori_Boss.mcaddon` を開いて取り込みます。
2. ワールド設定で **電子 独 ボス BP / RP** の両方をオンにします（白石白夜のアドオンと同時に入れても大丈夫です）。
3. スポーンエッグ「電子 独のスポーンエッグ」を使うか、`/summon hitori:denshi_hitori` で呼び出します。

## BGM とレコード
| 状況 | 流れる曲 |
|---|---|
| 独が出現してから HP50% まで | eight「隔絶された記憶」（ループ） |
| **↓FREEDOM DiVE↓ 解放後**（HP50%以下） | xi「FREEDOM DiVE」（ループ） |
| 撃破 | 4秒かけてフェードアウト |

- BGM は `/music` コマンドで流すので、**設定の「音楽」の音量**で大きさが変わります（0 だと聞こえません）。
- ワールドを読み込み直しても、独がいれば BGM は再開します。
- 撃破すると、レコード **「隔絶された記憶」**（専用アイテム）をドロップします。ジュークボックスで聞けます。
  - 統合版のカスタムレコードは、バニラのレコード音にしか対応していません。そのため、**このパックを入れたワールドでは、バニラのレコード「11」を鳴らしても「隔絶された記憶」が流れます**（レコード11の説明文も変わります）。

## 攻略の鍵：Glitch シールド
- 普段は **Glitch が展開されていて、あらゆるダメージが無効**になります。
- それでも、殴る・矢を当てるたびに **「GLITCH 負荷」** がたまります（画面下に `■■■□□□` で表示されます）。
- 負荷が上限（通常は10、HP50%以下では13、最終形態では15）に達すると、Glitch が耐えきれずに **強制解除（FATAL ERROR）** されます。
  - 独はその場に崩れ落ち、**3.5秒間スタン**します。この間だけダメージが通ります（近接70%・飛び道具50%）。
  - スタンが終わると爆風で周りを吹き飛ばし、**3秒間の「再構築中」**（負荷を受け付けない）を経て Glitch が再起動します。
- 負荷は **1秒ごとに1ずつ下がります**。手を止めずに当て続けることが大切です。
- 連打対策として、0.5秒より短い間隔のヒットは数えません。
- **過負荷放出**：負荷が上限の少し手前まで来ると、ヒットのたびに35%の確率で爆風を放って周りを吹き飛ばし、負荷が4下がります。
- **人数補正**：強制解除されたとき、周り40マス以内のプレイヤー人数に応じて、独が受けるダメージが減ります（2人で−20%、3人で−40%、4人以上で−60%）。

## 宿敵：白石白夜
- 白石白夜のアドオンも入れていると、2人は**お互いを敵として攻撃し合います**。技も相手に当たります。
- 白夜の攻撃も Glitch の負荷になります。
- 2人が出会ったとき、1回だけ**「宿敵」の会話カットシーン**が流れます。

### 形態の変化
- **↓FREEDOM DiVE↓（HP50%）**：空から ↓ が降り注ぎ、「落下」の能力が解放されます。ノイズが激しくなり、Glitch の負荷上限が8に上がります。BGM が「FREEDOM DiVE」に切り替わります。
- **🤍Re: End of a Dream💙（HP25%・1回だけ）**：カットシーン（顔のアップ → 真上からの俯瞰）のあと、回転する3本のノイズビームを6秒間放ちます（各13）。最後は周囲8マスを吹き飛ばします（22）。ビームと一緒に走って逃げてください。

## カメラ演出（v1.2）
カットシーン中は、近くのプレイヤーはカメラを操作できず、移動もできません。そのかわりダメージを受けず、HUD も一時的に隠れます。独もその間はダメージを受けません。
| 場面 | 内容 |
|---|---|
| 登場 | ノイズ混じりの細かいカット割り → 遠景から寄って名乗り、手を振る |
| ↓FREEDOM DiVE↓（HP50%） | 見上げるアングル → 真上からの落下視点 → 頭から急降下して着地 |
| Re: End of a Dream（HP25%） | 顔のアップ → 真上からの俯瞰 |
| 撃破 | 崩れ落ちた独のまわりをカメラが回り、ノイズになって消える |

## 演出
- Glitch 展開中は、体に RGB ノイズが走り、テクスチャがずれ、体や首がカクッとブレます。
- 強制解除中はノイズが消え、膝から崩れ落ちて、まわりにエラーダイアログが浮かびます。
- 「バグったゲーム」を表す T ポーズ、欠損テクスチャ（ピンクと黒）、RGB がずれたカウントダウン数字、エラーダイアログを使っています。
- 画面の点滅（`/camera fade`）と画面の揺れがあります。

## 注意
- スコアボード `hitori_glitch` と `hitori_players` を自動で作ります。
- ピースフルにすると独が消え、BGM だけが残ることがあります。そのときは `/music stop` で止めてください。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。
- 爆風はブロックを壊しませんが、近くの額縁や絵画は壊れることがあります。

## 作り直し方（開発者向け）
- 必要なもの：Pillow と ffmpeg
- 技を調整したいときは、`tools/generate.py` 冒頭の数値（`GLITCH_LIMIT`、`STUN`、`HP` など）を変えて実行します。
- **音源は著作物なので、このリポジトリ（公開）には入れていません。** 初回だけ、曲ファイルを指定してビルドしてください。2回目以降は、変換済みの音源を引き継ぎます。

```bash
python3 tools/generate.py skin.png --bgm 隔絶された記憶.mp3 --dive Freedom_Dive.mp3
```

- `.mcaddon`（`dist/`）にも音源が入るので、リポジトリには含めていません。
