# ボスアドオン「月島 風花」（統合版） v1.0

秘密結社「花鳥風月」の社長にして怪盗、**月島 風花（つきしま ふうか）**のボスアドオンです。
赤く塗られたスナイパーライフル「アウトロー・レッドノート」を持ち、**距離を保ちながら撃ち、攻撃はひらりと避け続ける**すばしっこいボスです。背後にはずっと、スタンド「牙」が浮かんでいます。

## 導入方法
1. `dist/TsukishimaFuuka_Boss.mcaddon` を開いて取り込みます（古いバージョンは先に削除してください）。
2. ワールドの設定で、ビヘイビアパック「月島 風花 ボス BP」を有効にします（リソースパックは自動で付きます）。
3. スポーンエッグ「月島 風花のスポーンエッグ」で呼び出します。
> 推奨バージョンは 1.21 以降です（`/camera`・`/hud`・`/fog` を使います）。

| 項目 | 内容 |
|---|---|
| 体力 | 1500（60% で「花鳥風月」、30% で「鳥獣戯画」） |
| 移動 | 近づかれたら離れ、遠すぎたら 16 マスくらいまで寄る。**近接攻撃はしない** |
| 身長 | 155cm（少し小さめ） |

## 攻略の鍵
### 回避ゲージ（鳥）
- 風花は**回避ゲージが残っている間、どんな攻撃もひらりと避けます**（羽が舞い、横や後ろへ跳ぶ）。避けるたびにゲージが 1 減ります。
- ゲージは時間で回復します（第一形態は最大 4、花鳥風月から最大 6、鳥獣戯画から回復が 2 倍速）。
- **ゲージが 0 のとき**（アクションバーに「回避ゲージ切れ！」）は攻撃が当たります。連続で攻撃して削り切りましょう。
- 人形がいるときは、避けると人形のところへ移動します（move）。

### 狙っている間は避けられない
- **狙撃・ハイジャンプからの射撃・DXL-5・霧の中の射撃**で狙いをつけている間は、回避できません（体がうっすら赤く光ります）。**ここが最大の攻撃チャンス**です。
- 狙撃は「赤い照準線で狙い続ける → 照準線が点滅して固定 → 発砲」の順です。**点滅したら横へ動けば避けられます**。弾は壁を貫通します。

### 無限の回転（ACT4）
- スタンド「牙」が力を溜めて放つ、回転する爪弾です。最初の 1 秒だけ追ってきます。
- 当たると「無限の回転」: **1 → 2 → 4 → 8 → 16** と、倍々のダメージを受け続けます（防具を貫通）。
- 止める方法は 2 つ: **風花の 5 マス以内に近づく**（回転を返して風花に大ダメージ）か、**誰かが風花に攻撃を当てる**（集中が切れて全員の回転が止まる）。

## スタンド「牙」
- 登場演出の最後に現れ、**戦闘中はずっと風花の右肩の後ろに浮かんでいます**（攻撃が終わっても消えません）。
- 普通のモブなので、**誰からでも見えます**。攻撃は当たりません。
- 爪弾（5 連射）と、ACT4「無限の回転」を撃ちます。

## 形態とカメラ演出
| 場面 | 内容 |
|---|---|
| 登場 | 煙玉の中から降り立って名乗り、ライフルを構える → **スタンド「牙」が現れる** |
| **花鳥風月**（HP60%） | 花（攻撃力アップ）→ 鳥（回避ゲージ 6）→ 風（素早さアップ）→ 月（近くの全員の強化効果を打ち消す） |
| **鳥獣戯画**（HP30%） | 鳥（回避ゲージの回復 2 倍）→ 獣（2 回行動）→ 戯（盗む技を解禁）→ 画（演出が終わった瞬間に動く） |
| 撃破 | 座り込んで笑い、「花鳥風月、撤収！」と煙玉で消える → 「討伐成功」 |

## ほかのボスと一緒に
白石白夜・電子 独・ソフィア・ハート・東雲 永々のアドオンも入れていると、お互いを敵として戦います。初めて出会ったときは、ひとこと交わして「VS」が表示されます。

## 注意
- スコアボード `fuuka_bird` と `fuuka_players` を自動で作ります。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。霧が残ったときは `/fog @s remove fuuka_mist` で消せます。

## 作り直し方（開発者向け）
```bash
python3 fuuka_boss/tools/generate.py skin.png
```

### 個人用: スタンドの見た目を、手元の Stand_disc アドオンのものにする
```bash
python3 fuuka_boss/tools/generate.py --tusk 手元のアドオン.mcaddon
```
- 通常版に加えて、`fuuka_boss/personal/TsukishimaFuuka_Boss_personal.mcaddon` ができます。スタンドの**見た目（モデル・テクスチャ・モーション）だけ**を、指定したアドオンのファイルから読み込みます。動き方・攻撃はこのアドオン側のものです。
- 元のアドオンの作者はファイルの再配布を禁止しているので、**個人用ファイルは自分だけで使い、ほかの人には渡さないでください**。`personal/` は公開リポジトリには入りません（`.gitignore`）。
