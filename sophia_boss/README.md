# ボスアドオン「ソフィア・ハート」（統合版） v1.5

「多分神様」ソフィア・ハートのボスアドオンです。**バランス型・手数重視**で、近接・魔法・弾幕・銃・召喚・時間操作と、多種多様な攻撃を次々に繰り出します。右手には紺碧刀（ダイヤの剣）を持っています。

## v1.5 の変更点（近接攻撃のモーション・演出中のルール）
- **通常攻撃（近接）を 4 連コンボに作り直しました**：溜め → 踏み込みながら打つ → 振り抜き → 戻り、と全身を使うモーションです。振るたびに次の技へ切り替わります：袈裟斬り → 左ジャブ → 回し蹴り → 突き
- **演出中は、ボス同士で手出しできなくなりました**：
  - どれかのボスの登場演出（ほかのカットシーンも）が始まると、近く（64 マス以内）のほかのボスはその場で一時停止し、演出が終わるまで攻撃しません。止まっている間は無敵です。
  - 演出中・一時停止中のボスは狙われず、技も当たりません。
  - 演出が終わると、自動で戦闘に戻ります。

## v1.4 の変更点（ボス同士の戦闘 AI を改良）
- **技の狙いが「一番近い敵」に**：プレイヤーだけでなく、ほかのボスにも技を向けて使うようになりました。ボス同士でも、瞬間移動・突進・飛び道具・範囲攻撃で戦います（プレイヤーとだけ戦うときの狙いは今までと同じ。クリエイティブのプレイヤーは狙いません）。
- **近距離技・遠距離技の選び方**も、プレイヤーではなく「一番近い敵」との距離で決めるようにしました。
- **立ち回りの技を追加**（プレイヤー相手にも使います）：
  - **ステップ・ショット**：後ろへ跳んで間合いを取り、弾幕 3 発で返す
  - **回り込み（右・左）**：相手の横へ回り込みながら詰めて、横から攻撃する

## v1.3 の変更点
- **4体のボスが全員敵同士に**（白石白夜・電子 独・ソフィア・ハート・東雲 永々）：
  - ほかのボスのアドオンも入れていると、お互いを狙って戦い、**技も相手のボスに当たります**。
  - 初めて24マス以内で出会うと、ひとこと交わして「VS」が表示されます（白夜と独は、これまでどおり専用のカットシーン）。
  - 相手のアドオンが入っていなくても、エラーにはなりません。
- **アニメーションをさらになめらかに**：
  - モーションのキーを 1 秒あたり 20 → **50** に増やしました（ファイルは大きくなります）。
  - **技の出だしと終わりのつなぎ**を長めのクロスフェードに。技の最後のポーズから待機へ、ふわっと戻ります（回転技のあとも逆回転しません）。
  - **振り向き**：瞬間移動して振り向くときや、tick ごとに回る技も、なめらかな回転に見えるようにしました。
  - **走り出し・止まり際**：走りのモーションがゆっくり出入りします。待機中のしぐさも、走り出すとふわっと消えます。
  - **通常攻撃**：振り始めと振り終わりで腕の向きが飛ばないようにしました。
  - **のけぞり**：一瞬でのけぞって、なめらかに戻るようにしました（カクカクした段差をなくしました）。
  - 技の途中でポーズを止めているときも、わずかに呼吸して揺れるので、固まって見えません。
- **一閃神速の斬り抜け**が、一瞬のワープではなく、数 tick かけて駆け抜ける高速移動になりました（当たり判定のタイミングは同じです）。

## v1.2 の変更点（アニメーション・演出のブラッシュアップ）
- **モーション全体をなめらかに**：ポーズとポーズの間を曲線でつなぐようにしました（止めるところはピタッと止まります）。
- **金色の軌跡**：刀を振ると刀身に沿って、拳や蹴りでは手足に沿って、金色の残光が残ります。
- **通常攻撃が「刀 → 左拳 → 回し蹴り」の順番に**：振るたびに次の技へ切り替わります。
- **待機中のしぐさ**：ときどき刀をくるっと回したり、首をかしげたりします。
- 走ると足元に土煙が立ちます（宙に浮いているあいだは出ません）。
- **着弾の手応え**：大技が地面に当たると、破片が飛び散り、土煙の輪が広がります。
- **カットインを追加**：ヴァルドガーラ（足元から見上げる）、低速弾幕（真上から見下ろす）。
- 倒すと「**討伐成功**」のタイトルが出ます。

## v1.1 の変更点
- **モーションが動かない不具合を修正**：撃破演出のポーズの書き方が原因で、モーションのファイルごと読み込まれていなかった可能性が高いので直しました。棒立ちで移動したり、技のモーションが出なかったりする問題が直るはずです。
- **弾幕が見えない不具合を修正**：弾を「光る球のモデル」にしました（遅い弾＝ピンク、普通＝金、速い弾＝青）。暗い所でも見えます。当たると火花と音が出ます。
- **モーションを作り直し**：待機（呼吸・重心移動・刀のゆらぎ）、走り（前傾・弾み）、被弾時ののけぞりを追加しました。**内なる宇宙のあとは宙に浮いて移動**します。技を使いながら移動するときも足が動きます。
- 適応のあとは、**左目（ラプラスの目）が青く光ります**。
- 自動回復システムの機体が光るようになりました。

## 導入方法
1. `dist/SophiaHeart_Boss.mcaddon` を開いて取り込みます（古いバージョンは先に削除してください）。
2. ワールド設定で **ソフィア・ハート ボス BP / RP** の両方をオンにします（白夜・独のアドオンと同時に入れても大丈夫です）。
3. スポーンエッグ「ソフィア・ハートのスポーンエッグ」を使うか、`/summon sophia:sophia_heart` で呼び出します。

> 推奨バージョンは 1.21 以降です（カメラ演出に `/camera` と `/hud` を使います）。

### 手数の多さを支える仕組み
- **連続行動（バースト制御アーツ:終式）**：技が終わったとき、一定の確率（30%〜55%）でそのまま次の技を出します。
- **MISS（軽やかなステップ）**：殴られたとき12%の確率で、ひらりと横に避けて1秒間無敵になります。
- **リフバリアΩ**：最大8秒間、攻撃を**6回まで**受け止める障壁を張ります（画面下に `◆◆◆◇◇◇` で表示）。6回当てると **BARRIER BREAK** して、2秒間よろめきます。
- **人数補正**：周り40マスのプレイヤーが2人で−20%、3人で−40%、4人以上で−60%のダメージ軽減（5秒ごとに数え直す）。

## 形態とカメラ演出
カットシーン中は、近くのプレイヤーはカメラを操作できず、移動もできません。そのかわりダメージを受けず、HUD も一時的に隠れます。ソフィアもその間はダメージを受けません。

| 場面 | 内容 |
|---|---|
| 登場 | 光の柱の中を舞い降りる → 着地して魔法陣 → オッドアイのアップで名乗る |
| **適応**（HP60%） | 一瞬止まる → 目のアップ → 魔法陣と電撃が広がる → 俯瞰。以降、体に電気をまとう |
| **内なる宇宙**（HP30%・必殺技） | 世界が宇宙に塗り替わる（霧・星空・銀河）→ 鎖で縛られる（遅くなる）→ 4秒後に収束（周囲14マスに24ダメージ）。**カットシーンが終わったら14マスの外へ** |
| **再臨**（ほぼ倒れたとき・1回だけ） | 崩れ落ちる → 光の柱 → HP約50%まで回復して立ち上がる → 神核融解（紫の炎をまとう） |
| 撃破 | 座り込んだソフィアのまわりをカメラが回り、光の粒になって消える → 「討伐成功」 |
| カットイン | 魔力砲・次元斬・紅・一閃神速・クロノスピア・ヴァルドガーラ・低速弾幕の前に一瞬入る |

## ほかのボスと一緒に
白石白夜・電子 独・東雲 永々のアドオンも入れていると、**お互いを敵として攻撃し合います**。技も相手に当たり、ほかのボスの攻撃はリフバリアΩでも数えられます。初めて出会ったときは、ひとこと交わして「VS」が表示されます。

### おまけ：東雲と一緒に
東雲 永々のアドオンも入れていて、東雲の近くにソフィアがいると、東雲に一度だけ「おすわり！」と言われ、**3秒間土下座してしまいます**（その間は無防備です）。

## 注意
- スコアボード `sophia_barrier` と `sophia_players` を自動で作ります。
- 爆風はブロックを壊しませんが、近くの額縁や絵画は壊れることがあります。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。霧が残ったら `/fog @s remove sophia_universe` で消せます。
- キャラシの技のうち、他作品の固有技（術式・領域展開・骨やブラスターなど）は、その作品の再現になってしまうため入れていません。

## 作り直し方（開発者向け）
`tools/` の Python ファイルを書き換えて、`python3 tools/generate.py skin.png` を実行すると、パックと `.mcaddon` が作り直されます（Pillow が必要です）。
