# ボスアドオン「ソフィア・ハート」（統合版） v1.0.1

「多分神様」ソフィア・ハートのボスアドオンです。**バランス型・手数重視**で、近接・魔法・弾幕・銃・召喚・時間操作と、多種多様な攻撃を次々に繰り出します。右手には紺碧刀（ダイヤの剣）を持っています。

## 導入方法
1. `dist/SophiaHeart_Boss.mcaddon` を開いて取り込みます。
2. ワールド設定で **ソフィア・ハート ボス BP / RP** の両方をオンにします（白夜・独のアドオンと同時に入れても大丈夫です）。
3. スポーンエッグ「ソフィア・ハートのスポーンエッグ」を使うか、`/summon sophia:sophia_heart` で呼び出します。

> 推奨バージョンは 1.21 以降です（カメラ演出に `/camera` と `/hud` を使います）。

### 手数の多さを支える仕組み
- **連続行動（バースト制御アーツ:終式）**：技が終わったとき、一定の確率（30%〜55%）でそのまま次の技を出します。
- **MISS（軽やかなステップ）**：殴られたとき12%の確率で、ひらりと横に避けて1秒間無敵になります。
- **リフバリアΩ**：最大8秒間、攻撃を**6回まで**受け止める障壁を張ります（画面下に `◆◆◆◇◇◇` で表示）。6回当てると **BARRIER BREAK** して、2秒間よろめきます。
- **人数補正**：周り40マスのプレイヤーが2人で−20%、3人で−40%、4人以上で−60%のダメージ軽減（5秒ごとに数え直す）。

## 形態とカメラ演出
カットシーン中は、近くのプレイヤーはカメラを操作できず、移動もできません。そのかわりダメージを受けず、HUD も一時的に隠れます。ソフィアもその間はダメージを受けません。

| 場面 | 内容 |
|---|---|
| 登場 | 光の柱の中を舞い降りる → 着地して魔法陣 → オッドアイのアップで名乗る |
| **適応**（HP60%） | 一瞬止まる → 目のアップ → 魔法陣と電撃が広がる → 俯瞰。以降、体に電気をまとう |
| **内なる宇宙**（HP30%・必殺技） | 世界が宇宙に塗り替わる（霧・星空・銀河）→ 鎖で縛られる（遅くなる）→ 4秒後に収束（周囲14マスに24ダメージ）。**カットシーンが終わったら14マスの外へ** |
| **再臨**（ほぼ倒れたとき・1回だけ） | 崩れ落ちる → 光の柱 → HP約50%まで回復して立ち上がる → 神核融解（紫の炎をまとう） |
| 撃破 | 座り込んだソフィアのまわりをカメラが回り、光の粒になって消える |
| カットイン | 魔力砲・次元斬・紅・一閃神速・クロノスピアの前に一瞬入る |

## おまけ：東雲と一緒に
東雲 永々のアドオンも入れていて、東雲の近くにソフィアがいると、東雲に一度だけ「おすわり！」と言われ、**3秒間土下座してしまいます**（その間は無防備です）。

## 注意
- スコアボード `sophia_barrier` と `sophia_players` を自動で作ります。
- 爆風はブロックを壊しませんが、近くの額縁や絵画は壊れることがあります。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。霧が残ったら `/fog @s remove sophia_universe` で消せます。
- キャラシの技のうち、他作品の固有技（術式・領域展開・骨やブラスターなど）は、その作品の再現になってしまうため入れていません。

## 作り直し方（開発者向け）
`tools/` の Python ファイルを書き換えて、`python3 tools/generate.py skin.png` を実行すると、パックと `.mcaddon` が作り直されます（Pillow が必要です）。
