# ボスアドオン「白石白夜」（統合版） v1.3

刀鍛冶「白石白夜（村正）」をボスとして追加するアドオンです。手に持っている鉄の剣は日本刀という設定です。

## 導入方法
1. `dist/ShiraishiByakuya_Boss.mcaddon` を開くと、マイクラに自動で取り込まれます（古いバージョンが入っている場合は、先に削除してください）。
2. ワールド設定で、ビヘイビアパックに **白石白夜 ボス BP**、リソースパックに **白石白夜 ボス RP** を入れます。
3. 呼び出し方は次の2通りです。
   - スポーンエッグ「白石白夜のスポーンエッグ」を使う
   - コマンド `/summon byakuya:shiraishi_byakuya` を打つ

> 実験的機能は使っていません（推奨バージョンは 1.21 以降）。

### 宿敵：電子 独
- 電子 独のアドオンも入れていると、2人は**お互いを敵として攻撃し合います**。技も相手に当たります。
- 白夜の斬撃は、独の Glitch に負荷をかけます（独のスタンを狙えます）。
- 2人が24マス以内で初めて出会ったとき、1回だけ**「宿敵」の会話カットシーン**が流れます。

### 距離を見て技を選ぶAI
- 一番近いプレイヤーが **7マス以内**にいるとき：近接技を多めに使います。
- **7マスより遠い**とき：遠距離技を多めに使います。
- 遠くに逃げても、高い所に登っても、安全な場所はありません。

## 形態の変化
- **終焉化（HP60%）**：カットシーンのあと、自己再生し、移動と技が速くなります。体に炎をまといます。
- **最終演技（HP25%・1回だけ）**：カメラワーク付きのカットシーンのあと、約3.5秒の猶予を置いて、半径16マスへ32ダメージ＋爆風を放ちます。**カットシーンが終わったらすぐ16マス以上離れてください。** それ以降は最終形態になり、体が赤く光ります。

## カメラ演出（v1.3）
カットシーン中は、近くのプレイヤーはカメラを操作できず、移動もできません。そのかわりダメージを受けず、HUD も一時的に隠れます。ボスもその間はダメージを受けません。
| 場面 | 内容 |
|---|---|
| 登場 | 遠景から寄っていき、煙管をふかす白夜 → 目元のアップで名乗り → 抜刀 |
| 終焉化（HP60%） | 低いアングルから回り込む → 真上からの俯瞰で爆炎 → 顔のアップ |
| 最終演技（HP25%） | 顔のアップ → 膝をつく姿を横から → 回り込み → 空撮 → 顔へ急接近 |
| 宿敵 | 白夜と独の肩越しショットを切り替えながら会話 → 空撮で「FIGHT!」 |
| 撃破 | 膝をつく白夜のまわりをカメラが回り、桜になって消える |
| カットイン | 百花繚乱・鞘鳴りの前に、一瞬だけ顔や手元のアップが入る |

## 演出
- 技ごとに専用のモーションがあります（居合の構え、宙に浮いてからの振り下ろしなど）。
- オリジナルのパーティクルは約80種類あります（斬撃、衝撃波、炎の柱、ビーム、桜吹雪など）。
- 雷・流星刀・遠当てなどは、来る前に予兆が出ます。
- 重い攻撃では画面が揺れます。
- 最終演技中は、まわりが赤黒い霧に包まれます。

## 注意
- 天地雷鳴の雷で、まわりの地面が燃えることがあります。
- 受け流し・業火螺旋・最終演技の爆風は、ブロックは壊しませんが、近くの額縁や絵画は壊れることがあります。
- もしカメラや HUD が戻らなくなったら、`/camera @s clear` と `/hud @s reset all` で戻せます。
- 霧が残ってしまったときは、`/fog @s remove byakuya_final` で消せます。
- 技を調整したいときは `tools/` の中の Python ファイルを書き換えて、`python3 tools/generate.py` を実行してください（Pillow が必要です）。パックと .mcaddon が作り直されます。
