# ボスアドオン「白石白夜」（統合版）

刀鍛冶「白石白夜（村正）」をボスとして追加するアドオンです。手に持っている鉄の剣は日本刀という設定です。

## 導入方法
1. `dist/ShiraishiByakuya_Boss.mcaddon` を開くと、マイクラに自動で取り込まれます。
2. ワールド設定で、ビヘイビアパックに **白石白夜 ボス BP**、リソースパックに **白石白夜 ボス RP** を入れます。
3. 呼び出し方は次の2通りです。
   - スポーンエッグ「白石白夜のスポーンエッグ」を使う
   - コマンド `/summon byakuya:shiraishi_byakuya` を打つ

> 実験的機能は使っていません（推奨バージョンは 1.21 以降）。

## ステータス
| 項目 | 値 |
|---|---|
| HP | 800 |
| 近接攻撃 | 12 → 16（終焉化）→ 20（最終演技後）。当たると鈍足になる |
| 耐性 | 落下・炎・溶岩・雷・溺れ・窒息・魔法・棘のダメージを受けない。飛び道具のダメージは半分。ノックバックしない |
| 撃破報酬 | 名刀「村正」（鉄の剣：ダメージ増加V、火属性II、耐久力III、ドロップ増加III、修繕）、鉄20個、「団子」（金リンゴ）6個、エンチャント金リンゴ、不死のトーテム、ネザライトインゴット1〜3個、経験値500 |

## 技一覧
| 技 | 内容 |
|---|---|
| 瞬閃 | 一番近いプレイヤーの背後に瞬間移動して斬る（14） |
| 天地雷鳴 | プレイヤーの位置に雷を何度も落とす |
| 火炎の狂滅 | 回転しながら炎の輪を広げる。範囲8マスに2回の炎ダメージ |
| 水没の重滅 | プレイヤーを浮かせて落とし、さらに溺れダメージ、鈍足、採掘速度低下 |
| 樹海の誘滅 | プレイヤーを自分の方へ引き寄せて斬る。さらに毒 |
| スコーピオン | 足元と周りの地面から牙を出す |
| 千本投擲 | プレイヤーの頭上から矢を降らせる |
| ホッパー | 4秒間ダメージを受けない。殴られるとまわりに反撃する |
| 武装を解除する程度の能力 | 成功率50%（キャラシ通り）。成功すると8秒間、近接攻撃が効かなくなる |
| 鋼糸 | プレイヤーの動きを止め、背後に回って斬る |
| **集散**（HP50%以下から） | 回転しながら6回連続で斬る |
| **無刀 無残**（HP50%以下から） | 暗闇にしてから、衝撃波で大ダメージ（16）＋衰弱 |

### 形態の変化
- **終焉化（HP50%）**：自己再生し、移動と技が速くなります。体に炎をまといます。
- **最終演技（HP20%・1回だけ）**：7.5秒間ダメージを受けず、その後に半径16マスへ30ダメージを与えます。**16マス以上離れれば避けられます。** それ以降は最終形態になり、体が赤く光ります。

## 演出（v1.1）
- **技ごとの専用モーション**：居合の構えからの一閃、天に刀を掲げる、回転斬り、片膝をついて刀を地面に突き立てる、宙に浮いてから振り下ろす（最終演技）など
- **オリジナルのパーティクル（70種類）**：三日月の斬撃、地面を走る衝撃波、炎の柱、水の渦、木の葉の渦、地面から突き出る刀、降ってくる刀、六角形の反射板、鋼糸、残像、桜吹雪
- **予兆の表示**：雷や刃が来る場所の足元に、点滅しながら縮むリングが出ます（よく見れば避けられます）
- **画面の揺れ**：重い攻撃を受けると画面が揺れます
- **形態ごとの見た目**：終焉化中は体が橙色に脈打ち、炎をまといます。最終形態では体が赤く光り、魂の炎もまといます。最終演技中はまわりが赤黒い霧に包まれます
- **倒したとき**：片膝をつくポーズになり、桜吹雪が舞います

## 注意
- 天地雷鳴の雷で、まわりの地面が燃えることがあります。
- 技を調整したいときは `tools/generate.py` を書き換えて `python3 tools/generate.py` を実行すると（Pillow が必要です）、パックと .mcaddon が作り直されます。
