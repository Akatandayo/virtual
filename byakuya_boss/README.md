# ボスアドオン「白石白夜」（統合版） v1.2

刀鍛冶「白石白夜（村正）」をボスとして追加するアドオンです。手に持っている鉄の剣は日本刀という設定です。

## 導入方法
1. `dist/ShiraishiByakuya_Boss.mcaddon` を開くと、マイクラに自動で取り込まれます（古いバージョンが入っている場合は、先に削除してください）。
2. ワールド設定で、ビヘイビアパックに **白石白夜 ボス BP**、リソースパックに **白石白夜 ボス RP** を入れます。
3. 呼び出し方は次の2通りです。
   - スポーンエッグ「白石白夜のスポーンエッグ」を使う
   - コマンド `/summon byakuya:shiraishi_byakuya` を打つ

> 実験的機能は使っていません（推奨バージョンは 1.21 以降）。

## ステータス
| 項目 | 値 |
|---|---|
| HP | **2000** |
| 近接攻撃 | 12 → 16（終焉化）→ 20（最終演技後）。当たると鈍足になる |
| 技の間隔 | 3〜5秒 → 2〜3.5秒（終焉化）→ 1.5〜2.5秒（最終形態） |
| 耐性 | 落下・炎・溶岩・雷・溺れ・窒息・魔法・棘のダメージを受けない。飛び道具のダメージは半分。ノックバックしない |
| 撃破報酬 | 名刀「村正」（鉄の剣：ダメージ増加V、火属性II、耐久力III、ドロップ増加III、修繕）、鉄20個、「団子」（金リンゴ）6個、エンチャント金リンゴ、不死のトーテム、ネザライトインゴット1〜3個、経験値500 |

### 距離を見て技を選ぶAI
- 一番近いプレイヤーが **7マス以内**にいるとき：近接技を多めに使います。
- **7マスより遠い**とき：遠距離技を多めに使います。
- 遠くに逃げても、高い所に登っても、安全な場所はありません。

## 形態の変化
- **終焉化（HP50%）**：自己再生し、移動と技が速くなります。体に炎をまといます。
- **最終演技（HP20%・1回だけ）**：7.5秒間ダメージを受けず、その後に半径16マスへ30ダメージを与えます。**16マス以上離れれば避けられます。** それ以降は最終形態になり、体が赤く光ります。

## 演出
- 技ごとに専用のモーションがあります（居合の構え、宙に浮いてからの振り下ろしなど）。
- オリジナルのパーティクルは約80種類あります（斬撃、衝撃波、炎の柱、ビーム、桜吹雪など）。
- 雷・流星刀・遠当てなどは、来る前に予兆が出ます。
- 重い攻撃では画面が揺れます。
- 最終演技中は、まわりが赤黒い霧に包まれます。

## 注意
- 天地雷鳴の雷で、まわりの地面が燃えることがあります。
- 霧が残ってしまったときは、`/fog @s remove byakuya_final` で消せます。
- 技を調整したいときは `tools/` の中の Python ファイルを書き換えて、`python3 tools/generate.py` を実行してください（Pillow が必要です）。パックと .mcaddon が作り直されます。
