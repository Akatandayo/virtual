# スキンチェンジャー アドオン(マイクラ統合版)

アイテムを使う(右クリック / 長押し・タップ)と、用意したスキンに見た目が切り替わるアドオンです。

## 入れ方
1. `dist/SkinChanger.mcaddon` をダウンロードして開く(スマホなら「マインクラフトで開く」)。
2. ワールド設定で **ビヘイビアパック「スキンチェンジャー BP」** を有効にする(リソースパックは自動で付きます)。
3. ワールドを開き、クリエイティブインベントリの「アイテム」タブから **「スキンチェンジャー: スキン1〜5」** を取り出して使う。
4. **「スキンチェンジャー: 元のスキンに戻す」** で自分のスキンに戻ります。

コマンドでも入手できます: `/give @s skin_changer:skin_1` ~ `skin_5`、`/give @s skin_changer:reset`

| スキン5 | src/skins/5.png | Alex型(細腕) |

## しくみ
- BP の `entities/player.json` でプレイヤーに `skin_changer:skin`(0=元のスキン, 1〜5)というプロパティを追加。
- スクリプト(`@minecraft/server`)がアイテム使用を検知して、このプロパティを書き換え。
- RP の `player.entity.json` がプロパティの値を見て、自作レンダーコントローラーでスキン画像と体型を切り替えます。
- 他のプレイヤーからも変更後のスキンで見え、ワールドを出入りしても保持されます。

## スキンを追加・変更するとき
`src/skins/` に画像を置いて `build.py` の `SKINS` に1行足し、`python3 build.py` を実行すると `dist/SkinChanger.mcaddon` が作り直されます。

## 注意
- `player.json` / `player.entity.json` を上書きするため、同じファイルを上書きする他のアドオンとは同時に使えません。
