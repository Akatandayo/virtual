==============================================================================
 電子 独 (Denshi Doku)  --  MUGEN 1.1 キャラクター
==============================================================================

ゲームのバグが具現化した存在。常に宙に浮いている。
自分のデータ（HP）を削ることで力を得る「代償」の能力を持つ。

------------------------------------------------------------------------------
■ 導入方法
------------------------------------------------------------------------------
1. この DenshiDoku フォルダを MUGEN 1.1 の chars フォルダにコピー
2. data/select.def の [Characters] に次の1行を追加

     DenshiDoku/DenshiDoku.def

※ localcoord = 640,480 (HD) のキャラです。
※ カラーは6色 (x / y / z / a / b / c ボタンで選択)
     1: オリジナル   2: ネガ反転   3: ブルースクリーン
     4: ターミナル   5: クリムゾン 6: ヴェイパー

------------------------------------------------------------------------------
■ ボタン
------------------------------------------------------------------------------
  x / y / z : 弱 / 中 / 強 パンチ (マフラー攻撃)
  a / b / c : 弱 / 中 / 強 キック
  s         : 挑発 (パワー少し増加)

  方向は キャラが右向きのとき  F=→  B=←  D=↓  DF=↘  DB=↙

------------------------------------------------------------------------------
■ 代償システム (自傷能力)
------------------------------------------------------------------------------
 ・自分のHPが減るほど攻撃力が上がる (HP 1 で最大 1.5倍)
 ・一部の技は自分のHPを削って発動する
 ・自分で削ったダメージでは KO しない (最低 HP 1 が残る)

  技                 代償
  -----------------  ---------------------------------
  グリッチワープ      HP -2%   (OVERFLOW 中は無料)
  データラッシュ      HP -3%
  自傷バグ            HP -8%   → パワー +600, OVERFLOW 状態
  FATAL ERROR         パワー1本 + HP -5%
  SYSTEM CRASH        パワー3本 + HP -15%

 ◆ OVERFLOW 状態 (10秒)
    ・攻撃力さらに 1.15倍
    ・バグショットが3発同時発射になる
    ・グリッチワープのHP消費がなくなる
    ・赤いノイズのオーラが出る

------------------------------------------------------------------------------
■ 技表
------------------------------------------------------------------------------
【移動】
  →→                     グリッチダッシュ (残像つき高速移動)
  ←←                     バックステップ
  空中で ↑               二段ジャンプ

【投げ】
  相手の近くで → or ← + y   スカーフバインド

【通常技】
  立ち x / y / z          マフラー突き / 斬り / 振り下ろし
  立ち a / b              蹴り (下段判定ではない)
  立ち c                  グリッチピラー (浮かせ技)
  しゃがみ x              マフラー突き
  しゃがみ y / a / b      下段
  しゃがみ z              対空マフラー
  しゃがみ c              足払い (ダウン)
  空中 x / y / z / a / b  中段 (しゃがみガード不可)
  空中 c                  グリッチバースト (周囲攻撃)

  ※ 弱 → 中 → 強 の順にチェーンでつながる
  ※ 通常技は必殺技・超必殺技でキャンセル可能

【必殺技】
  ↓↘→ + P     バグショット
                データの塊を飛ばす。x / y / z で速さが変わる。

  ↓↙← + K     グリッチワープ          [HP -2%]
                a: 前へ瞬間移動  b: 相手の背後へ  c: 後ろへ退避

  →↓↘ + P     データラッシュ          [HP -3%]
                出始め無敵の上昇マフラー攻撃 (対空)。3ヒット。

  ↓↓ + P       自傷バグ                [HP -8%]
                自分のデータを壊してパワーを大量に得て、
                OVERFLOW 状態になる。

【超必殺技】
  ↓↘→↓↘→ + P   FATAL ERROR       [パワー1本 / HP -5%]
                  画面を横切るグリッチビーム。多段ヒット。

  ↓↘→↓↘→ + K   SYSTEM CRASH      [パワー3本 / HP -15%]
                  ガード不能の突進。当たると相手のデータを破壊し、
                  画面がクラッシュする。

------------------------------------------------------------------------------
■ CPU (AI)
------------------------------------------------------------------------------
  MUGEN 1.1 の AILevel に対応。AI レベルが高いほど積極的に動きます。

------------------------------------------------------------------------------
■ ファイル構成
------------------------------------------------------------------------------
  DenshiDoku.def   キャラ定義
  DenshiDoku.cns   基本設定・代償システム・ダッシュ・勝利/登場/挑発
  DenshiDoku.cmd   コマンドと CPU の思考
  attacks.st       通常技・投げ (mugen/tools/build_states.py で生成)
  specials.st      必殺技・超必殺技
  DenshiDoku.air   アニメーションと当たり判定 (自動生成)
  DenshiDoku.sff   スプライト (SFF v2, 自動生成)
  DenshiDoku.snd   効果音 (自動生成)

  スプライト・アニメ・音は mugen/tools のスクリプトで元イラストから
  生成しています。自分で描いた絵に差し替えたい場合は、Fighter Factory
  などで DenshiDoku.sff を開いて同じ番号の画像を置き換えてください。

  スプライト番号の目安
    0      立ち          11   しゃがみ       20/21  前後歩き
    41/44  ジャンプ      100  ダッシュ       130-132 ガード
    200-250  立ち通常技  400-450 しゃがみ通常技  600-650 空中通常技
    800/810  投げ        1000-1300 必殺技   3000/3100 超必殺技
    5000-5300  やられ    6000-6120 エフェクト  9000  顔グラ
